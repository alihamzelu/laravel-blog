# Laravel Blog Platform

A modern blog platform built with Laravel and Filament, featuring authentication, social interactions, and a clean UI built with Tailwind CSS.

---

## 🚀 Features

- User authentication (Register / Login)
- User profiles with customization
- Create, edit, delete blog posts
- Like & comment system
- Follow / unfollow users
- Category-based post system
- Powerful search functionality
- Admin dashboard (Filament)
- Light and Dark mode
- Notification
- Donation
- Bookmark
  

---

## 🛠 Tech Stack

- Laravel
- PHP
- MySQL
- Filament Admin Panel
- Tailwind CSS
